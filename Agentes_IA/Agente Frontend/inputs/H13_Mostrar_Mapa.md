# H13 - Mostrar Mapa Web

## Descripción
Como usuario, quiero visualizar un mapa de calidad del aire desde la página web para conocer el estado ambiental de diferentes zonas.

## Criterios de evaluación

- Se muestra un mapa interactivo.
- Se representan las zonas con información disponible.
- Los estados de calidad del aire se diferencian visualmente.
- El mapa permite desplazarse y cambiar el nivel de zoom.
- Se informa cuando no hay datos disponibles para una zona.
- Debe ser un calor.
