# H10 - Registro Web

## Descripción

Como usuario, quiero poder registrarme desde la página web para crear una cuenta y acceder a las funcionalidades de la plataforma.

## Criterios de evaluación

- El formulario permite introducir los datos necesarios para crear una cuenta.
- Se comprueba que los campos obligatorios estén completos.
- Se valida que el correo electrónico tenga un formato correcto.
- Se informa al usuario si el correo ya está registrado.
- Se muestra un mensaje de confirmación cuando el registro se completa correctamente.
