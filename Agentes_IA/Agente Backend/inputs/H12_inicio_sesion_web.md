# H12 - Inicio sesión Web

## Descripción

Como usuario, quiero iniciar sesión desde la plataforma web para acceder a las funcionalidades correspondientes a mi cuenta.

## Criterios de evaluación

- Existe un formulario con correo electrónico y contraseña.
- Se validan las credenciales mediante el sistema de autenticación.
- Se informa de los errores de autenticación.
- El acceso correcto redirige al usuario a la página correspondiente a su perfil o permisos.
