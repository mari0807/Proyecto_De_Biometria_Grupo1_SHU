# H18 - Mostrar Detalles Mapa Web

## Descripción
Como usuario, quiero visualizar los datos detallados de una zona seleccionada para conocer sus niveles de contaminación y su evolución.

## Criterios de evaluación

- Se muestran los valores de los contaminantes disponibles.
- Cada valor incluye su unidad de medida.
- Se indica la fecha, hora de las mediciones y ubicación.
- Se muestran gráficas de evolución cuando existen datos históricos.
- Se informa cuando no hay mediciones disponibles.
