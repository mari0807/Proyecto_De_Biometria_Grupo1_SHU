# H25 - Cerrar sesión Web

## Descripción

Como usuario, quiero poder cerrar mi sesión para finalizar el acceso a mi cuenta de forma segura.

## Criterios de validación

- Existe una opción para cerrar sesión.
- Al seleccionarla, se finaliza la sesión activa.
- Se eliminan o invalidan las credenciales de sesión almacenadas según corresponda.
- El usuario es redirigido a la pantalla de inicio de sesión.
- No se permite acceder a páginas privadas sin volver a autenticarse.
